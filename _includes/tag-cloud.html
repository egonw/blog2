{% comment %} Tag cloud of the most used tags, linking to the tag pages; the other tags are listed below it. Tags with a ':' (doi:, justdoi:, inchikey:, cito:, ...) are not tags in this sense and are skipped. Without JavaScript, the cloud tags are shown as a list of links sized by frequency; with JavaScript, d3-cloud lays them out as a word cloud.
