One rarely know feature of [Bioclipse](http://www.bioclipse.net) is that you
use it to run [R](http://www.r-project.org/) code. This functionality has been
around for a while from *experimental*, and recently updated to use [rJava](http://cran.r-project.org/web/packages/rJava/index.html)
by [Carl](http://twitter.com/#!/carlmasak). In the next months we will improve
passing around data between Bioclipse and the R session, providing a richer
chemometrics experience. And, with a bit of luck, it will be part of the upcoming 2.6
release.
